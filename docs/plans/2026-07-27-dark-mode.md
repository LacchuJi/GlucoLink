# Dark Mode Feature Implementation Plan

> **For Antigravity:** REQUIRED WORKFLOW: Use `.agent/workflows/execute-plan.md` to execute this plan in single-flow mode.

**Goal:** Implement a sleek, persistent Dark Mode theme toggle across Patient and Clinician workspaces.

**Architecture:** Define CSS custom properties (`--bg-main`, `--card-bg`, `--text-main`, `--border-color`, `--sidebar-bg`) in `globals.css` and `clinical.css`. Build a reusable `<ThemeToggle />` component that toggles `document.documentElement.setAttribute("data-theme", "dark" | "light")` and persists to `localStorage`.

**Tech Stack:** CSS Custom Properties, React Hooks (TypeScript), LocalStorage API.
